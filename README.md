# Optimization

A collection of optimization techniques implemented from scratch while
learning them through coursework.

## Motivation

The goal is to understand optimization algorithms from the ground up rather
than treating them as a collection of rules to memorize.

Each technique is explored through its mathematical formulation, intuition,
and implementation.

## Currently Implemented

### Simplex Method

A basic implementation of the simplex method for linear programming.

The current implementation focuses on understanding:

- Basic feasible solutions
- Basis selection and exchange
- Movement between vertices
- The ratio test
- The linear algebra behind simplex

## Future

This repository will grow as I encounter and learn new optimization
techniques throughout my coursework.

The implementations will evolve alongside my understanding of the underlying
mathematics.
